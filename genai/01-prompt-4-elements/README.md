# 1편: 같은 질문, 다른 답 — 좋은 프롬프트의 4요소

## 파일

| 파일 | 하는 일 |
|---|---|
| `prompt_compare.py` | 막연한 요청과 구체적인 요청을 보내 답의 길이와 내용을 비교 |
| `ablation.py` | 4요소(역할·대상·형식·제약)를 하나씩 빼고 3번씩 실행해 평균 글자 수 비교 |
| `sample_output_*.txt` | 영상을 만들 때 실제로 나온 실행 결과 |

## 실행

저장소 맨 위의 README대로 준비한 뒤:

```bash
cd genai/01-prompt-4-elements
python prompt_compare.py
python ablation.py
```

`ablation.py`는 API를 15번 호출합니다(프롬프트 5개 × 3번).
