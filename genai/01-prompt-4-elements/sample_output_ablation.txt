===== 4요소 전부: [258, 243, 252]자, 평균 251자 =====
**정의**: 리스트 컴프리헨션은 for문으로 리스트를 만드는 과정을 한 줄로 줄인 문법입니다.

**예제**: 1~5의 제곱 리스트

```python
# for문
result = []
for x in range(1, 6):
    result.append(x * x)

# 컴프리헨션
result = [x * x for x in range(1, 6)]
```

**주의**: 조건이나 반복이 여러 개 겹치면 오히려 읽기 어려우니, 그럴 땐 for문을 쓰세요.

===== 역할 빼기: [260, 239, 246]자, 평균 248자 =====
**정의**: 리스트 컴프리헨션은 for문으로 리스트를 만드는 코드를 한 줄로 줄여 쓰는 문법이다.

**예제**
```python
# for문
squares = []
for x in range(5):
    squares.append(x * x)

# 컴프리헨션
squares = [x * x for x in range(5)]
# 결과: [0, 1, 4, 9, 16]
```

**주의**: 조건이나 반복이 많아지면 오히려 읽기 어렵다. 복잡하면 for문을 쓰자.

===== 대상 빼기: [214, 215, 223]자, 평균 217자 =====
**정의**: 반복문과 조건을 한 줄로 써서 새 리스트를 만드는 문법입니다.

```python
# for문
squares = []
for x in range(5):
    squares.append(x**2)

# 컴프리헨션
squares = [x**2 for x in range(5)]
```

**주의**: 조건이나 중첩이 많아지면 읽기 어려우니, 복잡할 땐 for문을 쓰세요.

===== 형식 빼기: [291, 275, 263]자, 평균 276자 =====
리스트 컴프리헨션은 **반복문으로 리스트를 만드는 코드를 한 줄로 줄인 문법**이에요.

반복문:
```python
nums = []
for x in range(5):
    nums.append(x * 2)
```

컴프리헨션:
```python
nums = [x * 2 for x in range(5)]
```

조건도 붙일 수 있어요:
```python
evens = [x for x in range(10) if x % 2 == 0]
```

`[결과 for 변수 in 반복대상 if 조건]` 순서로 읽으면 됩니다.

===== 제약 빼기: [995, 994, 881]자, 평균 956자 =====
## 한 줄 정의
**리스트 컴프리헨션은 `for`문으로 리스트를 만드는 과정을 대괄호 `[ ]` 안에 한 줄로 줄여 쓰는 문법입니다.**

---

## 예제 코드: 1부터 5까지 각 숫자의 제곱 리스트 만들기

**① 익숙한 for문 버전**
```python
squares = []              # 1. 빈 리스트를 만들고
for x in range(1, 6):     # 2. 1부터 5까지 반복하면서
    squares.append(x * x) # 3. 제곱한 값을 하나씩 추가

print(squares)  # [1, 4, 9, 16, 25]
```

**② 리스트 컴프리헨션 버전**
```python
squares = [x * x for x in range(1, 6)]

print(squares)  # [1, 4, 9, 16, 25]
```

**어떻게 바뀌었나요?**

```
[ x * x    for x in range(1, 6) ]
   ↑              ↑
 append할 값     for문 머리 부분 그대로
```

- `for x in range(1, 6)` → for문의 첫 줄을 그대로 가져옵니다.
- `x * x` → `append()` 괄호 안에 넣던 값을 **맨 앞**에 씁니다.
- 빈 리스트를 만들고 `append`하는 과정은 대괄호 `[ ]`가 대신 해줍니다.

---

## 주의할 점: 너무 길게 쓰면 오히려 읽기 어렵다
리스트 컴프리헨션은 **간단한 작업을 짧게 쓸 때** 좋습니다. 조건이나 반복이 여러 개 겹치면 한 줄이 복잡해져서 무엇을 하는 코드인지 알아보기 힘들어집니다.

```python
# 😵 한눈에 이해하기 어려움
result = [x * y for x in range(5) if x % 2 == 0 for y in range(x) if y > 1]
```

**한 번 읽고 바로 이해되지 않는다면 그냥 for문으로 쓰세요.** 코드를 짧게 쓰는 것보다 읽기 쉽게 쓰는 것이 더 중요합니다.
